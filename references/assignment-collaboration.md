# Assignment collaboration

## Requirements summary

Read only the assignment and user-selected related files. Summarize objective, deliverable, required sections, length/format/naming/citation rules, data or evidence requirements, rubric priorities, effective deadline, submission method, and ambiguities. Separate explicit requirements from inference.

## Topic and idea discussion

Ask whether the user wants to develop an existing idea together or see several options. For options, compare feasibility, data availability, originality, effort, and risks. Continue conversationally until the user chooses a direction; do not assume a topic.

## Demo creation

Generate the format and depth the user requests: outline, report draft, notebook, analysis code, spreadsheet, slides, or another artifact. Label the result `Draft / Demo — Not Submitted` where appropriate. Keep placeholders for missing personal or empirical material. Run and verify code or analysis before describing outputs as results.

Creating a demo is local-only. After completion, offer revision or export options; do not mention upload as the default next action.
